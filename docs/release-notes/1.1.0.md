# Local Session Switcher 1.1.0

Launch-readiness release: extra local hosts, store package, docs, and a demo.

## Install from this zip

1. Download `local-session-switcher-1.1.0.zip` from this release.
2. Unzip it.
3. `chrome://extensions` → Developer mode → **Load unpacked** → pick the unzipped folder.

Chrome Web Store listing is in progress; until it is live, the zip is the install path.

## Added

- Optional host access for user-configured **local** origins: `*.test` (Valet/Herd), `*.local`, `*.localhost`, `*.internal`, loopback, and LAN IPs. Default grants stay `localhost` / `127.0.0.1` / `[::1]`. Remote hosts are refused. Chrome prompts per origin on save or first switch.
- Public homepage and privacy policy (GitHub Pages).
- Chrome Web Store listing copy, screenshots, and `pnpm store-pack` (clean zip + manifest checks).
- Bundled `skills/session-switcher-seed/assets/example.seed.json`.
- Demo GIF and refreshed screenshots.

## Docs

- README rewritten for Show HN / store readers: pitch, GIF, FAQ, extra hosts, privacy.
- Issue templates, PR template, code of conduct.
