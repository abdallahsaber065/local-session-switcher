# Local Session Switcher 1.2.0

Window-aware switching: each window context owns its session, cookie store, and badge.

## Install from this release

1. Download **`local-session-switcher-1.2.0.zip`** (clean store package) from this release.
   The raw `.output` zip is attached too if you prefer it.
2. Unzip it.
3. `chrome://extensions` → Developer mode → **Load unpacked** → pick the unzipped folder.

The Chrome Web Store listing is still in progress; until review completes, the zip is the
install path.

## Added

- **Window-scoped switching** — a switch applies only to the window that triggered it
  (popup, side panel, right-click menu, or keyboard shortcut). Storage injection and reloads
  no longer reach into other windows.
- **Private-window isolation in both directions** — normal and private windows use their own
  cookie stores end to end (switch, capture, detection, queued injections). Switching inside a
  private window requires the extension's **Allow in incognito** permission; the popup now
  explains that clearly when it is missing.
- **Per-window badge** — the toolbar initials follow the active user of each window context:
  private tabs show the private session's user, normal windows the normal one. Additive
  `activeUserByScope` state with legacy fallback; no seed/schema change.

## Fixed

- The popup no longer shows only empty skeletons when a private-window startup message fails —
  background messages time out with an actionable hint, and session detection can no longer
  block the user list from rendering.
- Private switching resolves the cookie-store id **inside the private window** and passes it
  to the background (Chrome's service worker could not always enumerate Brave's private store),
  with `current` / non-current store fallbacks.

## Notes

- The switch pipeline is unchanged: set new → prune leftovers → reload; auth recipe URLs must
  resolve to the project's own origins.
- Normal windows still share one cookie jar per browser class; private windows are fully
  separate. For two users at once, use a second profile or keep one in a private window.
