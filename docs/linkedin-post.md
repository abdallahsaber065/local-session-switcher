كام Incognito tab فاتحها دلوقتي عشان بس تجرب صلاحيات الـ Admin والـ User في السيستم اللي شغال عليه؟


لو شغال على Web Apps فيها Role-based Access Control (صلاحيات ومستخدمين مختلفين)، فأكيد عارف وجع الدماغ بتاع:

أعمل Logout > أدخل يوزر الـ Admin > أجرب > أعمل Logout > أدخل الـ Normal User.. أو تفضل تفتح كذا Browser جنب بعض لحد ما الرامات تشتكي.


عشان أخلص من اللفة دي، عملت Chrome Extension فكرته ببساطة إنك بتبدل بين كل الـ Roles والحسابات في ثواني وبضغطة زرار واحدة من الـ Side Panel، مع تحكّم ذكي وأوتوماتيك في الـ Auth State:


أهم المميزات اللي بيقدّمهالك:

- بيدعم كذا بروجكت في نفس الوقت، وبيتعامل مع كل مشروع حسب الـ Auth Strategy بتاعته (سواء شغال بـ Cookies، أو JWT في LocalStorage/SessionStorage، أو مزيج بينهم).


- مش هتحتاج تكتب ملف الداتا يدوي؛ جهزت Agent Skill جاهزة في الـ Repo تخلي الـ AI يحلل الـ Auth بتاع مشروعك ويطلعلك ملف الـ seed.json بالبروفايلات جاهز للاستخدام علطول


-بيعمل أوتوميشن لعملية تسجيل الدخول للـ Test Accounts بدل ما تقعد تكتب الإيميل والباسورد كل شوية بإيدك.


- بيراقب الـ JWT والـ Tokens ويعملها Refresh تلقائي في الخلفية بحيث السيشن تفضل شغالة ومتقعش فجأة وأنت بتتيست.


- بيلقط الـ Auth State الحالية بالكامل بضغطة زرار، وتقدر تتنقل بين أي بروفايل للتاني لحظياً وفي نفس التاب.


-  شغال في الـ Chrome Sidepanel جنبك مباشرة، خفيف ومش بيغطي على الشاشة ولا يعطل فتحك للـ DevTools.
