Auth API (for recipes)

POST /api/auth/login with { "email", "password" } — alice@test.local / alice, bob@test.local / bob. JWTs expire after 45 seconds and /api/auth/refresh renews them, so the extension's reuse → refresh → login lifecycle is testable. GET /api/auth/csrf serves a CSRF token; GET /api/auth/me reports 200/401 for the cookie session.
